# Tech Explorer
Site educativo estático sobre carreiras em TI (HTML, CSS e JavaScript puros, sem dependências).

## Estrutura
index.html · css/style.css · js/data.js (dados) · js/main.js (lógica) · assets/favicon.svg

## Executar localmente
Abra `index.html` no navegador, ou rode `python3 -m http.server` na pasta e acesse http://localhost:8000.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie os arquivos (Add file > Upload files, ou `git init`, `git add .`, `git commit`, `git push`).
3. Em Settings > Pages, escolha Deploy from a branch, branch `main`, pasta `/ (root)`.
4. Acesse o endereço indicado em alguns minutos.
Caminhos são relativos; se algo não carregar, confira maiúsculas/minúsculas nos nomes dos arquivos.

## Limitações
- Dados salariais ainda não incluídos (sem fonte verificada, nada foi inventado).
- Links de vagas abrem pesquisas externas; a disponibilidade depende de cada plataforma.
